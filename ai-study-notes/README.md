# AI/ML Knowledge Base for Cloud Architect Interview

面向云架构师（特别是 GCP/AWS Storage 方向）的 AI/ML 核心知识梳理。

本知识库从**存储架构师**的视角出发，系统梳理 AI/ML 领域的核心概念，每个主题都包含：
- 概念原理讲解（教材级展开）
- 表格/对比总结
- GCP 对应服务映射
- AWS 对照
- **存储视角加餐**（IO 模式、吞吐/IOPS/延迟、容量成本、存储选型）
- 面试话术（直接可用的答题模板）

## 🎯 适用人群

- 准备 GCP Professional Cloud Architect / ML Engineer 认证的工程师
- AWS 存储架构师想了解 AI/ML 领域的存储需求
- 需要从存储视角理解 AI workload 的云架构师

## 📖 使用建议

1. **系统学习**：按 01→08 顺序通读，建立完整知识体系
2. **面试突击**：直接看每篇末尾的「面试话术」部分
3. **存储对标**：关注每篇的「存储视角加餐」，理解 AI workload 对存储的真实需求
4. **云服务对照**：每篇末尾的 GCP/AWS 对照表，快速建立服务映射
